================================================================================
Acknowledgements — no code from any of the following is included
================================================================================

Address Library for SFSE
  Required at runtime. The plugin reads the versionlib-*.bin database to
  resolve engine addresses for your game version. No Address Library code is
  used — src/AddressLib.cpp is an original parser for that file format.

SFSE (Starfield Script Extender)
  The plugin loads as an SFSE plugin. It links no SFSE code; the plugin
  version structure in src/main.cpp is declared by hand to match the SFSE ABI.

CommonLibSF (https://github.com/libxse/commonlibsf)
  Consulted for interface facts only — the SFSE plugin structure layout and
  its flag values. Not linked, and none of its code is present.

Bethesda Game Studios
  Starfield.

The Genesis mod author, for the original report and symptom detail on the
pause/unpause VRAM spike, and the Nexus users who reported and helped
characterise the quit-to-desktop hang in 0.9.
